## 🌱 TribuMama

An iOS, Android and web product that helps mothers in the same neighbourhood
meet in small, verified local groups. 1,000+ mothers and 100+ active tribes so
far.

The product repo is private (it holds real people's data), so I put together a
public case study with diagrams and real code:
**[tribumama-engineering](https://github.com/martattack/tribumama-engineering)**

- 📈 **Growth:** programmatic SEO pages built from live data, structured data
  for search and AI assistants, install attribution, and paid campaigns
  measured against geographic holdouts
- 🧪 **Measured activation:** a cohort KPI funnel defined once in SQL, so every
  report and agent sees the same numbers
- 🤖 **AI-first engineering:** production errors become GitHub issues every
  morning. Labelling one starts a Claude Code agent that opens a tested draft
  PR, and a person reviews before anything merges
- 🏗️ **Stack:** Expo, React Native, Next.js, TypeScript, Supabase (Postgres,
  PostGIS, Realtime, Edge Functions), PostHog, Sentry, GitHub Actions
